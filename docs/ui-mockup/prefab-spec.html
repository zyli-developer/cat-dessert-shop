② ToolButton · 道具栏三态 金币购买制 · 无次数库存（对齐 PRD §经济）

A 可用
B 金币不足

三态共用同一底座，只切：滤镜去色 / 价格底色 / 锁徽标 / 焦糖填充
// 一个 prefab，三态用一个枚举切换显隐/材质
ToolButton (Button)
├─ Base      Sprite 圆角方 108²,r26, 象牙白 + 3px 白内圈 + 砂色外环
├─ Icon      Sprite 54², 暖棕；不足态→灰 #B59C80
├─ PriceChip 底部 -15 悬挂, 焦糖糖纸 + coin + "15"
├─ LockBadge 右上 -12 圆徽, 仅"不足"态显示
└─ Grayscale "不足"态: 灰度滤镜/灰色材质, opacity .8
属性设计(750)说明
尺寸 / radius108² / 26命中区达标
图标54²暖棕 → 不足态 #B59C80
底座描边3px 白内圈 + 3px 砂环inset + 外 ring
价格挂签bottom −15焦糖糖纸；不足→粉红
锁徽标44²,右上 −12仅不足态
看广告态焦糖填充+厚底6价格变 "+10"
价格数值锤子15 / 洗牌15无次数；不够→看广告+10
状态机：afford = coin ≥ 15。afford=false → 切 B（去色+锁+价格转红，并引导指向看广告）；点看广告 → coin+10、回到 A。不要做 ×N 次数角标——PRD 是金币购买制。
搭建顺序建议：先做 JellyButton（全站复用最广），用 9-slice 圆角图 + 渐变；再做 ToolButton 把三态做成一个 prefab + 枚举。完整色值 / 容器几何 / 物理参数见同目录 ../cocos-mapping.md，图标切图见 icons-export/export.html。
