> 目的：把 `docs/ui-mockup/*.html` 高保真稿与 `docs/plans/*`（PRD）逐项比对，列出**矛盾 / 越界 / 缺失**，每条给出证据、影响、修法与**需你拍板**的选项。

## 🔴 Blocker

### B1. 每回合初始金币不一致（15 vs 20 vs 18）
- 证据：PRD `04-economy.md:12,27`、`07-mvp-scope.md:32`、`cocos-mapping.md:144` = **15**；`game.html:182` `coins=20`；`states.html:119` 用 18。
- 影响：15 是核心付费钩子（用 1 次道具即归零→逼出"看广告+10"漏斗）；20/18 让玩家用完仍剩余，循环失效。三处数字不一 = 无单一真源。
- 修法：mockup 起手金币统一改 **15**（HUD、`coins=15`、不足态<15）。
- 决策：☐ 锁定 15（推荐） ☐ 改为其它：______

### B2. 通关结算页缺「分享」按钮
- 证据：`03-ui.md:101,108,169`、`04-economy.md:53-57`、`07-mvp-scope.md:19,48` 均要求结算页分享，且"分享率≥5%"为考核指标；`win.html:52-55` 仅有 翻倍/返回/下一关。分享被挪到首页顶栏（`home.html:39`，无分数上下文）。
- 影响：结算页是唯一合规分享触发点（shareAppMessage 带分数卡）。
- 修法：`win.html` 底部按钮区加「分享」CTA；明确首页顶栏分享是否保留。
- 决策：☐ 结算页加分享，首页分享保留 ☐ 结算页加分享，首页分享删 ☐ 其它：______

### B3. 侧边栏复访（navigateToScene）UI 与 PRD 双双缺失
- 证据：mockup 与 `docs/plans/*` 全文无 `侧边栏/navigateToScene/sidebar`。
- 影响：抖音小游戏标准回流渠道（`launch_from=sidebar`），loading 处应按启动 query 分支。
- 现状：工程侧 `HomeScene.ts` 已把首页分享按钮接到 `onSidebarClicked`（`DouyinSDK.navigateToSidebar`），代码已部分覆盖；但设计文档未定义入口/落地。
- 决策：☐ MVP 纳入（补 loading/home 入口说明） ☐ 明确延期到 vX ☐ 其它：______

## 🟠 Major

### M1. 顾客区 / 道具栏 / NEXT 三处位置文档打架
- 证据：mockup `game.html` = 顾客**上方横排**(`:76`)、道具栏**底部**(`:146`)、NEXT**中右**(`:103`)；PRD `03-ui.md:63-64,79-80` = 顾客**左侧竖排**、道具栏**顶部第二行**、NEXT**右上角**；`cocos-mapping.md:108-110`、`01-gameplay.md:36` 也说 NEXT 右上角。
- 影响：实现者拿到冲突指令。底部道具栏/上方顾客（合成飞向顾客）其实更顺手，但必须三方对齐。
- 修法：选定一套，回写 `03-ui.md` 布局段 + `cocos-mapping.md`。
- 决策：☐ 以 mockup 为准（顾客上排/道具底部/NEXT中右），回写 PRD ☐ 以 PRD 为准，改 mockup ☐ 折中：______

### M2. 顾客「耐心环」暗示了不存在的机制
- 证据：`game.html:79,85,91` 画了耐心倒计时环（粉环=快没耐心）；PRD `02-levels.md:32` 失败条件**仅容器溢出**，无顾客超时离开。
- 影响：UI 承诺了游戏没有的规则。
- 决策：☐ 删除耐心环 ☐ 给 PRD 增加顾客耐心/超时机制 ☐ 其它：______

### M3.「每日礼包」是死路（无屏/无后端/非 MVP）
- 证据：`home.html:76-79` 有入口带"1"角标；无礼包弹窗、无 PRD 屏、无后端领取接口；`08-roadmap.md:61` 把每日签到列为 **v2.1**。
- 影响：UI 承诺 PRD/后端都不提供的功能。
- 修法：MVP 首页移除该入口，或降级为禁用"即将开放"。
- 决策：☐ 移除 ☐ 降级为"即将开放"占位 ☐ MVP 就要做（需补后端） 

### M4. 缺 PRD 强制的「家园（即将开放）」首页占位
- 证据：`03-ui.md:46,54`、`07-mvp-scope.md:22`、`08-roadmap.md:30` 要求首页有置灰"家园(即将开放)"预告按钮；`home.html` 无。
- 决策：☐ 首页补「家园(即将开放)」占位 ☐ PRD 删除该要求

### M5.「营业提醒 / 体力回满通知」控制不存在的系统
- 证据：`settings.html:74-76` 有"营业提醒/体力回满时通知我"开关；PRD 全文无**体力**系统（仅 mockup 出现）；抖音无通用服务端推送，PRD/后端无 subscribeMessage。
- 决策：☐ 删除该开关 + "体力"文案（推荐） ☐ 立项 subscribeMessage + 体力系统

### M6. 排行榜口径与后端不符
- 证据：`rank.html` 好友/全国都显示单一"分数"(如26,540)且有"本周最佳"(`:82`)；后端 `06-backend.md:90,155` 好友榜按**最高回合数**、全为**历史榜无周维度**。
- 影响：UI 造了后端不支持的"周榜"维度，并错标好友榜口径。
- 决策：☐ 好友榜改显回合数、去掉"本周" ☐ 后端增加周榜+分数好友榜 ☐ 其它：______

### M7. 结算页缺「本关好友排名」
- 证据：`06-backend.md:88-103,157`、`03-ui.md:96-100` 要求结算页显示本关好友 top-3 + 高亮"你"；`win.html` 仅分数+猫币。
- 决策：☐ `win.html` 增加 3 行本关好友排名块 ☐ PRD 删除该要求

### M8. 缺登录失败/授权拒绝 & 激励视频加载失败状态
- 证据：`03-ui.md:23-24`、`06-backend.md:168`（401→重登）需处理登录失败；`loading.html:92-101` 是无限循环纯进度条，无 →home 切换、无失败/重试分支；抖音常见 no-fill，但 4 个广告位无"广告加载失败/暂无广告"反馈。
- 现状：真实登录按钮由 `LoadingScene.ts` 运行时生成（可登录+离线兜底），但设计稿未画这些态。
- 决策：☐ 补 登录失败重试 + 广告 no-fill 反馈两态 ☐ 仅补登录态 ☐ 暂不补

### M9. 容器只画到 Lv6，Lv7/Lv8 缺席
- 证据：`01-gameplay.md:18-26`、`cocos-mapping.md:115-123` 定义 8 级（Lv7=160/Lv8=188）；`game.html:130-137` 只渲染 Lv1–Lv6。
- 影响："两个 Lv8(376) 刚好进 400 宽"的核心手感(`01-gameplay.md:28`)从未在稿里验证。
- 决策：☐ mockup 补一张含 Lv8/双Lv8 的容器布局以验证几何 ☐ 不补（仅口头确认）
