## 1. 三条核心修复（廉价感根因，必须做）

1. **删掉所有黑色描边 → 暖棕 `#5A4636`**
   现在很多 Label 都开了 `Outline`（黑边 width 3）。全部改成暖棕，或直接关描边。这是「廉价感」头号来源。
   - 主文字 `#5A4636`，次要文字降到 60~70% 透明度的同色。

2. **玻璃糖果按钮 → 果冻按钮（JellyButton）**
   按 `prefab-spec.md` 的三节点结构搭：`Shadow(厚底+环境投影) / Face(面色渐变+顶高光) / Label`。按下整体下沉 6px。
   - 四种语义色（主 CTA 草莓粉 `#F5879B` / 货币焦糖黄 / 正向薄荷绿 / 中性）→ 对应底深色见规格表。

3. **扁平描边图标 sheet → 统一线条图标**
   用 `icons-export/` 里的图标替换 `buttons-sheet`。Cocos Sprite 只吃位图，所以：
   - 打开 `icons-export/export.html`，尺寸选 144（大图标可选 192），「下载全部 PNG」。
   - 放进 `client/assets/resources/textures/ui/`，编辑器里换 SpriteFrame。
   - 命名已对齐现有约定：`icon_settings / icon_prev / icon_next / icon_hammer / icon_shuffle / icon_pause / icon_coin …`

## 2. 容器几何修正（游戏内最重要，对齐 PRD）

现在游戏内容器比例画反了。按 `cocos-mapping.md`「容器几何」段改：

- **容器 400×600（2:3 竖高）**，对应 PRD 设计分辨率。
- **警戒线**：容器顶部约 10% 处一条虚线；元素超线 5 秒倒计时（PRD §6）。
- **甜品直径表**（折算 720 后 ×0.96）：Lv1=40 / Lv2=58 / Lv3=75 / Lv4=96 / Lv5=116 / Lv6=141 … Lv8=188，**严格递增**，两个 Lv8 并排刚好填满容器宽。
- **当前元素**顶部居中 + 落点引导线；**NEXT 预览**右上角。
- 物理参数（重力 -960 / 弹性 0.3 / 摩擦 0.5 等）填进 Box2D，见对照表。

## 3. 道具栏金币模型（别做成库存/次数！）

PRD §2 是**金币购买制，无使用次数**：

- 锤子 **15 金币**（消除任意一个）/ 洗牌 **15 金币**（重排）/ 看广告 **+10**。
- **不要做 ×N 次数角标。** 判定逻辑：`afford = coin >= 15`。
- 三态按 `prefab-spec.md`：可用 / 金币不足（去色+锁+价格转红+引导气泡指向看广告）/ 看广告反馈（+10 Toast）。
