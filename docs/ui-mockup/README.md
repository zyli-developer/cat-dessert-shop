# 猫咪甜品店 · UI 改版稿（使用说明）

治愈手绘烘焙风的高保真 UI 改版稿。**复用你现有工程的全部插画**（背景 / 猫咪 / 甜点 / Logo），
只重做了 UI 外壳（按钮、卡片、图标、HUD、各类状态）。画布 **750 × 1334**（抖音竖屏），可点击交互。

> 🛠 **要落回 Cocos？** 三份对照物：① 图标切图 [`icons-export/export.html`](icons-export/export.html)（选尺寸一键下 PNG）② 控件规格 [`prefab-spec.html`](prefab-spec.html) / [`prefab-spec.md`](prefab-spec.md)（果冻按钮 + 道具栏三态）③ 色值/几何/物理 [`cocos-mapping.md`](cocos-mapping.md)（与 `docs/plans/` 的 PRD 对齐）。本文件夹只是设计参考，**不含可运行的 Cocos 代码，不影响现有工程**。

---

## 一、怎么看

- 预览面板会自动打开根目录 `index.html` → 它跳转到本文件夹的 `index.html`（画廊启动器）。
- 也可直接打开 **`ui-redesign/index.html`**：6 块屏幕装进手机框并排，点任意屏看 750×1334 大图；
  底部「状态补充 · State UIs」横幅进入 `states.html`。
- 单独看某一屏：直接打开对应的 `*.html` 即可（互相独立、可单独切图）。

## 三、`game.html` 的可点交互（这一轮新增）

| 操作 | 行为 |
|---|---|
| 点 HUD 左上 **暂停** | 弹出暂停弹窗：继续 / 重新开始 / 主页 + 音乐·音效就地开关 |
| 点 **锤子（15）** | 扣 15 金币进入「选择消除模式」：容器变暗、顶部提示条、甜点悬停高亮；点中一个即消除并退出；点右上 ✕ 取消并退还 15 |
| 点 **洗牌（15）** | 扣 15 金币，弹出「已重新摆放」Toast |
| 点 **看广告 +10** | 金币 +10，金币芯片弹跳，弹出「+10 金币」Toast |
| 金币 < 15 时 | 锤子/洗牌自动去色 + 加锁 + 价格转红，弹出引导气泡指向脉动的「看广告」按钮；点不可用道具提示「先看广告补充」 |

> 局内起手金币设为 **20**（贴合 PRD「每回合金币偏紧」）：用一次道具就逼近不足，
> 能完整体验 **够用 → 使用 → 不足 → 看广告 → 恢复** 的链路。

`states.html` 里还把这些状态逐个配了「出现时机」说明，A 组那张卡可点按钮在「够用↔不足」间切换。

## 四、设计系统速查（详见 `css/app.css` 顶部 `:root`）

| 角色 | 值 | 用途 |
|---|---|---|
| 纸底奶油 | `#FFF7EC` | 页面背景 |
| 卡片象牙 | `#FFFDF8` | 卡片 / 面板 |
| **暖棕** | `#5A4636` | 文字 + 描边（**取代原来的硬黑描边**，是统一感的关键） |
| 草莓粉 | `#F5879B` | 主色 / 主 CTA（每屏最多用两次） |
| 焦糖黄 | `#F7C156` | 货币（猫币） |
| 薄荷绿 | `#8AD2AE` | 正向 / 确认 / 复活 |

- 字体：标题 `Baloo 2`（圆润果冻感）+ 正文系统中文字体。
- 按钮：厚底投影 + 顶部内高光 + 按下下沉的「果冻」风（取代玻璃糖果贴图）。
- 图标：统一暖棕线条 SVG（取代原扁平描边 sheet）；猫币为爪印金币。
- 阴影/描边一律暖棕调，不用纯黑、不用紫色渐变、不堆 emoji。

## 五、落回 Cocos 时（已备好三份对照物）

1. **图标切图** → 打开 `icons-export/export.html`，选尺寸（默认 144，UI 大图标可选 192）→「下载全部 PNG」→ 放进 `client/assets/resources/textures/ui/`，在编辑器里把对应 `Sprite` 的 SpriteFrame 换成新图。命名已对齐你现有 `icon_*` 约定（齿轮→`icon_settings`、翻页→`icon_prev/next`）。Cocos 的 Sprite 只吃位图，所以用 PNG；矢量源在 `svg/`。
2. **控件规格** → `prefab-spec.html`（可视化标注）/ `prefab-spec.md`（纯数值）给出果冻按钮、道具栏三态的尺寸、阴影分层、节点树、状态机。
3. **色值 / 几何 / 物理** → `cocos-mapping.md`：`:root` token、容器 **400×600（2:3）**、甜点直径表、警戒线位置、Box2D 参数、道具金币模型。
- 标注在 750 设计空间，落 PRD 的 720×1280 整体 **×0.96**。
