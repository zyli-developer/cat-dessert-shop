# Prefab 像素级规格 — JellyButton + ToolButton 三态

> 配套可视化：`prefab-spec.html`（带尺寸标注 + 爆炸分层图）。
> 数值取自 `css/app.css`，标注在 **750×1334 设计空间**；落 PRD 的 **720×1280** 整体 **×0.96**。
> 完整色值 / 容器几何 / 物理参数见 `cocos-mapping.md`。

---

## ① JellyButton（果冻按钮）

替代旧的玻璃糖果贴图。一个结构，四种语义色只换「面色 + 底深色」。

### 节点树（自下而上）
```
JellyButton (Button)
├─ Shadow   Sprite 圆角胶囊  色=底深色      Y 偏移 +8
├─ Face     Sprite 圆角胶囊  竖向渐变 hi→base
│   ├─ HiLight  顶部 4px 白条  opacity .5（内高光）
│   └─ Label    粗体 800 白字  文字阴影 0 2 rgba(0,0,0,.10)
└─ 按下：Face/Label 整体 Y −6，Shadow 高度 8→2
```

### 阴影分层（box-shadow 五层，从内到外）
| # | 层 | 值 | 作用 |
|---|----|----|------|
| ① | 顶部内高光 | `inset 0 4 0 rgba(255,255,255,.5)` | 受光顶面 |
| ② | 面色渐变 | `linear-gradient(180°, hi, base)` | 主体 |
| ③ | 底部内阴影 | `inset 0 -5 0 rgba(0,0,0,.07)` | 面/底转折 |
| ④ | 厚底深色 | `0 8 0 {底深色}` | 果冻厚度（按下→2） |
| ⑤ | 环境阴影 | `0 16 22 rgba(120,80,40,.24)` | 柔和落地 |

### 数值
| 属性 | 设计750 | Cocos720 |
|---|---|---|
| height 常规 / lg | 96 / 118 | 92 / 113 |
| radius | 999（胶囊，=高/2） | =高/2 |
| padding 左右 | 38 / lg 50 | 36 / 48 |
| font-size 常规 / lg | 36 / 44 | 35 / 42 |
| 字重 / 字色 | 800 / #fff | 同 |
| 厚底 offset | 8 →按下 2 | 8 → 2 |
| 按下位移 | translateY 6 | Y −6 |

### 语义色 → 底深色
| 变体 | 面色（hi→base） | 底深色 | 字色 |
|---|---|---|---|
| primary 主色 | `#FF9DB0 → #F5879B` | `#D9596F` | #fff |
| butter 焦糖 | `#FCD37E → #F7C156` | `#DA9B30` | #7A4E16 |
| mint 薄荷 | `#A6E2C6 → #8AD2AE` | `#56AE88` | #1F5B41 |
| ghost 幽灵 | 象牙白 `#FFFDF8` | `#E4D2B5` | 暖棕#5A4636（+2px砂描边） |

## ② ToolButton（道具栏三态）

**金币购买制，无次数库存**（对齐 PRD 经济篇）。一个 prefab，枚举切三态。

### 节点树
```
ToolButton (Button)
├─ Base      Sprite 108² r26  象牙白 + 3px白内圈 + 3px砂色外环
├─ Icon      Sprite 54²       暖棕；不足态→灰 #B59C80
├─ PriceChip 底部挂签 −15      焦糖糖纸 + coin + 价格
├─ LockBadge 右上 −12 圆徽 44²  仅「不足」态显示
└─ Grayscale 「不足」态滤镜      grayscale(.92) + opacity .8
```

### 三态
| 态 | 触发 | 表现 |
|---|---|---|
| A 可用 | `coin ≥ 15` | 正常；图标暖棕；价格焦糖糖纸 |
| B 金币不足 | `coin < 15` | 去色+压暗、图标转灰、价格底色转粉红 `#FFE6EB`、右上加锁、引导气泡指向看广告 |
| C 看广告 | 独立按钮 | 焦糖填充 `#FCD37E→#F7C156` + 厚底6、价格显示 `+10` |

### 数值
| 属性 | 设计750 | 说明 |
|---|---|---|
| 尺寸 / radius | 108² / 26 | 命中区达标(≥88) |
| 图标 | 54² | 暖棕→不足#B59C80 |
| 底座描边 | 3px白内圈 + 3px砂环 | inset + 外 ring |
| 价格挂签 | bottom −15，高40 | 焦糖；不足→粉红 |
| 锁徽标 | 44²，右上 −12 | 仅不足态 |
| 价格数值 | 锤子15 / 洗牌15 | 无次数；不够→看广告+10 |

### 状态机
```
afford = coin >= COST(15)
afford == false  → 切 B（去色+锁+价格红+引导气泡 → 看广告）
点「看广告 +10」  → coin += 10 → 回 A
⚠ 不要做 ×N 次数角标 —— PRD 是金币购买制，不是库存制
```
