## 用法（和现有 9 张猫同一套流程）
1. 同一只猫的 3 个表情**在同一会话中连续生成**：先出 `idle` 作为基准，`happy`/`bye` 的 prompt 已带 `Same character as the previous image`，保证是同一只。
2. 生成 200×200，**抠白底**，按 `cat_<slug>_{idle,happy,bye}.png` 命名。
3. 放进 `client/assets/resources/textures/character/`（与现有 `cat_orange/blue/white` 同目录）。
