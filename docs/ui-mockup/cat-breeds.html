30 只全做需 30×3=90 张新图，对 4MB 主包是压力，且部分品种在 Q 版小尺寸下会"撞脸"（见下）。若先验证留存，建议先做视觉最不重复的 10 只：缅因猫 · 布偶猫✓ · 波斯猫 · 英短✓ · 无毛猫 · 折耳猫 · 暹罗猫 · 孟加拉豹猫 · 曼基康矮脚 · 大橘✓（其中 3 只已有，只需补 7 只）。

怎么把这份目录变成真正的资产

1️⃣ 配套文件 cat-asset-prompts.md 里有全部 30 品种 × 3 表情 = 90 条生成 prompt，严格沿用你 docs/plans/09-assets.md 的 Style Base 写法（chibi 拟人 + 同会话连续生成保证同一只猫三表情一致）。

2️⃣ 把 prompt 喂给你们现用的出图管线产出 200×200 PNG，抠白底，按 cat_<breed>_{idle,happy,bye}.png 命名放进 resources/textures/character/。

3️⃣ 撞脸提醒（Q 版小图下需靠服饰 + 瞳色 + 体型区分）：灰猫组（俄蓝/英短/沙特尔）、重点色组（布偶/暹罗/伯曼/喜马拉雅/东奇尼）、扁脸组（波斯/异国/喜马拉雅）。这也是建议先做 MVP 10 只的原因。

⚠️ 我无法直接画出与现有水彩风一致的 PNG 成品——上面"待生成"卡里的色块只是毛色占位，最终成品由 prompt 走你们的图像生成那一步产出。
