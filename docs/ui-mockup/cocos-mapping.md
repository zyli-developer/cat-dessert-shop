# Cocos 落地对照表 — 猫咪甜品店 UI 改版稿

> 把 `docs/ui-mockup/` 里的 HTML 高保真设计稿，翻译成 Cocos Creator 3.x 里能照着调的**数值规范**。
> HTML/CSS **不能**直接导入 Cocos——本表是给你 / 程序在编辑器里调 `Sprite` / `Label` / `Layout` / `prefab` 时的对齐依据。
>
> - 设计稿画布：**750 × 1334**（iPhone 标准竖屏）
> - 你工程设计分辨率：**720 × 1280**（见 `docs/plans/01-gameplay.md`）
> - 换算系数：`720 / 750 = 0.96`。本表凡涉及绝对尺寸，**已折算到 720×1280**，可直接填 Cocos。

---

## 0. 一句话原则（这次改版的灵魂）

> **删掉所有纯黑描边（`Label.enableOutline` 黑边 width 3），改用暖棕 `#5A4636`。**

这是廉价感的头号来源。你的插画本身的描边就是暖棕调，UI 文字也跟上，整体立刻统一。其余按钮 / 面板 / 图标只是把"玻璃糖果贴图 + 扁平描边 sheet"换成下面这套数值化的果冻组件。

## 1. 颜色 Token → Cocos 用法

Cocos `Color` 用 RGBA（0–255）或十六进制字符串。下表直接给十六进制。

| 角色 | 名称 | HEX | Cocos 落点 |
|------|------|-----|-----------|
| 页面纸底 | paper | `#FFF7EC` | 根节点底色 / 无背景图时的 `Camera.clearColor` |
| 卡片象牙白 | paper-2 | `#FFFDF8` | 卡片 / 弹窗 `Sprite`（白图 + 染色）|
| 面板砂色 | sand | `#F6E8D0` | 道具栏 / 二级面板底 |
| 面板深砂 | sand-2 | `#F0DBBB` | 面板内分区 |
| **主文字 / 描边** | **ink** | **`#5A4636`** | **所有 `Label.color`（替换黑色）**；描边若保留则用此色 width 2 |
| 次级文字 | ink-soft | `#8A7259` | 副标题 / 说明 |
| 弱文字 | ink-mute | `#B59C80` | 占位 / 禁用文字 |
| 细分隔线 | line | `#ECDABF` | 列表分隔 `Sprite` 高 2px |
| 卡片柔描边 | line-2 | `#DCC197` | 卡片外圈（用 `Sprite` 九宫格或 outline）|
| **主 CTA** | **pink** | **`#F5879B`** | 「开始营业」「下一关」主按钮底 |
| 主 CTA 高光 | pink-hi | `#FF9DB0` | 按钮顶部内高光渐变上端 |
| 主 CTA 厚底 | pink-dp | `#D9596F` | 按钮下方 8px 厚底（投影色）|
| 主 CTA 浅底 | pink-sf | `#FFE6EB` | 粉色 toast / 标签底 |
| 货币 / 金币 | butter | `#F7C156` | 金币芯片 / 金币数字高亮 |
| 金币厚底 | butter-dp | `#DA9B30` | 金币按钮厚底 |
| 正向 / 复活 / 确认 | mint | `#8AD2AE` | 「+10」按钮、确认、复活 |
| 正向厚底 | mint-dp | `#56AE88` | 上面的厚底 |
| 星级 | star | `#FFC53D` | 胜利星星填充 |

## 2. 字号 / 圆角 / 投影（折算到 720×1280）

> HTML 数值 ×0.96 ≈ Cocos 数值。下表已折算并取整。

| 用途 | 设计稿(750) | Cocos(720) | 字重 |
|------|-----------|-----------|------|
| 主按钮文字 | 36 | **34** | Bold/800 |
| 弹窗标题 | 52–60 | **50–58** | Bold |
| HUD 数值（金币/分数/关卡）| 32 | **31** | Bold，等宽数字 |
| 正文 / 列表 | 28 | **27** | Regular/Medium |
| 次级说明 | 24 | **23** | Regular |
| 角标 / 小标签 | 22 | **21** | Medium |

**圆角**（Cocos 用 `Sprite` 圆角图或 `Graphics`）：

| 名称 | 值(已折算) | 用途 |
|------|-----------|------|
| r-xl | 33 | 大弹窗 / 容器外框 |
| r-lg | 27 | 卡片 |
| r-md | 21 | 小卡 / 输入 |
| r-sm | 15 | 标签 / 芯片 |
| pill | 全圆 | 按钮 / 芯片胶囊 |

**投影**（Cocos 无 CSS 阴影，用「半透明黑图垫在下层 + 偏移」或 prefab 预制阴影层模拟）：
- 卡片软投影：`rgba(120,80,40,.16)`，Y 偏移 +12，模糊≈28 → 用一张羽化暖棕半透明图垫底。
- 果冻按钮"厚底"：在按钮 `Sprite` **下方 8px** 叠一层同形状的 `pink-dp` 实色图（这就是休闲游戏"汁感"的关键，不是阴影，是实体厚边）。
- 按下态：按钮整体 `position.y -= 4`，厚底变 4px。

## 3. 果冻按钮规格（替代玻璃糖果贴图）

一个按钮 = **3 层**，建议做成 prefab `JellyButton`：

```
JellyButton (Node)
├─ Shadow   (Sprite, pink-dp 实色, 同形状, y = -8)   ← 厚底
├─ Body     (Sprite, 主色填充, 圆角 pill)            ← 主体
│   └─ TopHi (Sprite, 白色 50%透明, 顶部 1/2 高)      ← 内高光
└─ Label    (Label, color = #FFFFFF, 主按钮)         ← 文字
```

- 主按钮：Body=`pink`，Label 白字，高 **92px**(折算)，左右内边距 ≥36。
- 货币按钮：Body=`butter`，Shadow=`butter-dp`。
- 正向/复活：Body=`mint`，Shadow=`mint-dp`。
- 命中区 ≥ **88×88**（抖音小游戏触控下限，宁大勿小）。
- 圆形图标按钮（暂停/设置/关闭）：白底 `paper-2` + 暖棕线条图标，直径 **64px**，`ink` 描线 width 2.4。

## 4. 游戏内容器几何 ★ 与 PRD 对齐（重点）

> 这是上一轮纠正过的硬伤——容器是 **2:3 竖高**，不是横宽。以下全部用你的 720×1280 设计分辨率。

| 项 | PRD 值 | 说明 |
|----|--------|------|
| **容器尺寸** | **400 × 600** | 严格 2:3，竖高杯型 |
| 容器水平居中，底部留顾客区 | — | 杯口在上、甜品向上堆 |
| **警戒线** | 容器顶部下方 **≈10%**（约 y=60 处一条虚线）| 超线触发 5 秒倒计时 |
| 当前元素 | 容器**顶部居中** + 落点引导虚线 | PRD §2 |
| NEXT 预览 | **右上角**小面板 | PRD §2 |

**甜品直径表**（PRD §1，按容器宽 400 的占比；这是合成进阶的视觉逻辑，务必等比，别再出现 lv1 比 lv2 大的倒挂）：

| Lv2 | 曲奇 | 56 | 14% | `dessert_lv2_cookie2.png` |
| Lv3 | 泡芙 | 72 | 18% | `dessert_lv3_puff.png` |

## 5. HUD / 道具栏数值（与经济 PRD 对齐）

> 见 `docs/plans/04-economy.md`。道具是**金币购买制，无次数**——不要做 ×N 库存角标。

**局内金币模型**：每回合初始 **15**；Lv8 合成 +50；看广告 +10。
- 锤子 🔨 = **15 金币**（消除任意元素）
- 洗牌 🔀 = **15 金币**（重排）
- 道具栏常驻「看广告 +10」按钮

**道具栏三态**（已在 `states.html` / `game.html` 演示，落 prefab 时做 3 个状态）：
1. **可用**：底 `sand`，价格 `butter` 字，可点。
2. **金币不足**（`金币 < 15`）：图标去色（灰度 `ink-mute`）+ 价格转红 `pink-dp` + 右上角锁；同时弹深色引导气泡指向脉动的「看广告 +10」。← 这就是你最初问的"道具没有可用数量"状态。
3. **锤子选择模式**：容器盖一层暗遮罩 + 顶部提示条 + 准星，甜点 hover 高亮；✕ 取消并**退还 15 金币**。

**分数**（PRD §5，指数递增 `10×2^(N-2)`）：Lv2 +10 / Lv3 +20 / Lv4 +40 / Lv5 +80 / Lv6 +160 / Lv7 +320 / Lv8 +640；Lv8 消除 +1000；服务顾客 +50/人。

**猫币奖励**（结算页，PRD §3）：⭐+5 / ⭐⭐+10 / ⭐⭐⭐+20；看广告翻倍。

## 7. 落地步骤建议

1. **先改色**：全工程 `Label` 黑色 / 黑描边 → `#5A4636`。改一处就能感到统一。一天内可见效。
2. **做 3 个基础 prefab**：`JellyButton`、`Card`（圆角+柔描边+软投影）、`IconButton`。其余 UI 拼这三件。
3. **校容器几何**：GameScene 容器改 400×600，甜品 `CircleCollider2D` 半径按 §4 表，加警戒线节点。
4. **对道具栏**：按 §5 三态做 prefab state，金币模型对齐。
5. **替图标**：把 `buttons-sheet` 扁平描边图标，换成本稿统一暖棕线条（可从 HTML 里的 inline SVG 导出 PNG/SVG）。
6. 预览随时对照：浏览器打开 `docs/ui-mockup/index.html`。
