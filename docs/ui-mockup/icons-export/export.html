图标切图导出 · icon export

26 个统一线条图标（暖棕 #5A4636，与游戏内渲染一致）。选好尺寸 → 一键下载 PNG → 拖进 Cocos 的 resources/textures/ui/ 即可替换旧的玻璃按钮 / 扁平图标。SVG 矢量源在同目录 svg/ 下。

用法（Cocos Creator 3.x）：把下载的 PNG 放到 client/assets/resources/textures/ui/（或你现有的 UI 贴图目录）， 在编辑器里把对应 Sprite 的 SpriteFrame 换成新图即可。命名已对齐你现有的 icon_* 约定 （齿轮→icon_settings、左右翻页→icon_prev/next）。 批量下载若被浏览器拦截，点一次地址栏的「允许多文件下载」即可。
