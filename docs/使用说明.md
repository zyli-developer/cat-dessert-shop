# 一起开猫店 · 使用说明（真机适配总纲）

> 这份是**整套交付的统一入口**，把「设计稿 → 切图/规格 → 落地 Cocos」一条线讲清楚，
> 重点是这几轮做的**真机尺寸适配、安全区、字体不爆框**三件事怎么用、怎么守。
> 各屏内容细节见设计稿目录 `ui-redesign/README.md`；控件像素标注见 `prefab-spec.html / .md`；
> 引擎侧改法见本目录 `安全区适配说明.md`。

---

## 0. 一句话先看懂

- **画布 = 720 × 1280**（抖音竖屏，和你 Cocos 工程设计分辨率 1:1）。
- 真机用 **fitHeight**：高度撑满、**只裁左右**。所以唯一的硬规矩是——
  **关键 UI 必须落在水平安全带 `[84, 636]` 之内**，顶部让出抖音胶囊，底部让出 Home 指示条。
- 字体：`Baloo 2` 只含拉丁字形，**中文永远回落系统黑体**；按钮已按「最坏情况（系统字体）」调好，
  且共享 `.btn` 加了 `white-space:nowrap`，**不会再折行撑破圆角**。

## 2. 怎么预览设计稿

1. 预览面板自动打开根 `index.html` → 跳到 `ui-redesign/index.html`（**画廊启动器**，各屏装进手机框并排）。
2. 点任意屏看 **720×1280 大图**；点底部「状态补充」横幅进 `states.html`。
3. 看单屏：直接打开对应 `*.html`（每屏互相独立，可单独切图）。

### 真机裁切验证（最重要）
**单独打开**某一屏（不是画廊缩略图）时，底部有个按钮可循环切三种视图：

| 视图 | 看什么 |
|---|---|
| **真机 19.5:9（iPhone）** | 默认。左右真的被裁，所见即玩家所见。 |
| **真机 20:9（安卓）** | 最长屏，裁得最狠，拿它压测最稳。 |
| **全画布 + 安全区** | 显示完整 720 宽，并叠加参考线：<br>· 红色斜纹 = 长屏会被裁掉的左右区<br>· 绿色虚线 = 安全带 `[84, 636]` 边界<br>· 右上虚线框 = 抖音胶囊位 |

**验证标准：切到「全画布 + 安全区」，红色斜纹区里不能有任何关键 UI；绿色虚线带内内容齐整。**

## 3. 真机适配规约（改稿/加屏都要守）

这些 token 在 `css/app.css` 顶部 `:root`，全部 7 屏共享：

| token | 值 | 含义 |
|---|---|---|
| 画布 | `720 × 1280` | `.stage` 固定尺寸，勿改 |
| `--safe-x` | `84px` | 长屏每侧最多被裁宽度 → **关键 UI 左右内缩 ≥ 84** |
| `--cap-top` | `100px` | 顶部状态栏 + 抖音胶囊保留带 → HUD 从此线下方开始 |
| `--safe-bottom` | `34px` | 底部 Home 指示条 → 底部按钮/道具栏上抬这么多 |

落地原则：
- **背景图铺满 720（甚至更宽兜底）**，长屏裁掉的是背景边缘，不心疼；
- **承重 UI（按钮、HUD、订单、道具、榜单）收进 `[84, 636]`**；
- 装饰元素（边角猫、甜点）**故意出血**没关系，被裁是预期效果。

## 4. 字体不爆框规约

**根因**（已用无头浏览器屏蔽 Google Fonts 复刻真机确认）：
`Baloo 2` 经 Google Fonts 在线加载，抖音 webview 常拉不到；且它**只含拉丁字形**，
中文 100% 回落 `PingFang / 微软雅黑`，字面更宽更高 → 按拉丁度量调的固定高度按钮被撑爆、折行。

**已做的系统级修复**（`css/app.css` 的 `.btn`）：
- `white-space:nowrap` —— 标签恒单行，杜绝折行撑破圆角；
- `line-height:1` + padding 收窄（`0 38px → 0 30px`）。
- win/fail 的长中文按钮（"看广告复活 30s"、三连按钮）单独再收了字号/padding。

**加新按钮时记住**：
1. 中文标签一律假设走系统黑体，**别靠 `Baloo 2` 的窄字宽**估宽度；
2. 固定高度的药丸按钮，内文必须能单行放下；放不下就**先缩 padding，再缩字号**，不要让它换行；
3. 想验证：用「屏蔽网络字体」的方式看（或直接信任已调好的 `.btn`，它就是按最坏情况调的）。

> 进阶（暂未做）：若要 mockup 里那种圆润中文手写感，需换一款**含中文字形**的字体（思源/站酷快乐体）并本地打包——会增体积，属视觉风格调整，不在「修溢出」范围。

## 5. 落地 Cocos

### 5.1 切图
打开 `icons-export/export.html` → 选尺寸（默认 144，大图标 192）→「下载全部 PNG」→
放进 `client/assets/resources/textures/ui/` → 编辑器里把对应 `Sprite` 的 SpriteFrame 换新图。
命名已对齐你现有 `icon_*` 约定。（Cocos Sprite 只吃位图用 PNG；矢量源在 `svg/`。）

### 5.2 控件规格
`prefab-spec.html`（可视标注）/ `prefab-spec.md`（纯数值）：果冻按钮、道具栏三态的尺寸、阴影分层、节点树、状态机。
标注**直接是 720×1280，1:1 无换算**。

### 5.3 安全区（引擎侧真正的根治）
已写入你的 Cocos 工程，可直接编译：

| 文件 | 状态 |
|---|---|
| `…/scripts/platform/SafeArea.ts` | **新增**：把宿主 `safeArea`+胶囊矩形换算成 720 设计单位的四向内缩 |
| `…/scripts/types/tt.d.ts` | 补 `safeArea` 字段 + `getMenuButtonBoundingClientRect()` 类型 |
| `…/scripts/ui/GameScene.ts` | `layoutGameUI()` 已接入 `safe.*`（金币芯片避开胶囊是关键改动） |

**用法**（套到 `HomeScene` / 各 `popups/*` 同理）：
```ts
import { SafeArea } from '../platform/SafeArea';

const safe = SafeArea.get();
const TOP = Math.max(62, safe.capsuleBottom + 8); // 顶栏压到胶囊/刘海下
this.anchor(btnPause, { top: TOP, left: 26 + safe.left });          // 左上
this.anchor(toolbar,  { bottom: 46 + safe.bottom, hCenter: 0 });    // 底部抬过指示条
this.anchor(coinChip, { top: TOP, right: 22 + safe.right + safe.capsuleWidth + 16 }); // 避开胶囊
```
- 弹窗大多居中、天然安全；只有**右上关闭按钮**要避让胶囊：`right: x + safe.right + safe.capsuleWidth`。
- 浏览器预览（拿不到 `tt`）自动回落保守值，与设计稿 `--cap-top:100 / --safe-bottom:34` 对齐，编辑器里不穿帮。
- 锁竖屏可忽略旋转；若会变更尺寸，resize 时调一次 `SafeArea.invalidate()`。
- **Canvas 不用动**：`720×1280 / fitWidth:false / fitHeight:true` 本就正确，左右裁切由 Widget 自动消化。

细节完整版见本目录 `安全区适配说明.md`。

## 6. 新增 / 修改一屏的检查清单

- [ ] 画布用 `720×1280`，复用 `css/app.css` + `js/stage.js`，别另写缩放。
- [ ] 关键 UI 左右内缩 ≥ `--safe-x(84)`；HUD 起点在 `--cap-top(100)` 下；底部元素上抬 `--safe-bottom(34)`。
- [ ] 纵向内容不超过 1280（按旧 1334 排的老值要往上收）。
- [ ] 每个固定高度按钮内文单行放得下（中文按系统黑体估宽）。
- [ ] 单独打开 → 切「全画布+安全区」→ 红色裁切区无关键 UI，绿色安全带内容齐整。
- [ ] 再切「真机 20:9」压最长屏。
